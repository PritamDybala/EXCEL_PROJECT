# EXCEL_PROJECT
This is a hands-on excel project where annual sales report of a store is created so it can improve the sales of the store by analyzing the previous data.



OBJECTIVE : Vindra Store wants to create an annual sales report for 2022 so that they can understand their customer and grow more sales in 2023.





Sample Questions : 
     1. Compare the sales and orders in a single chart.
     2. Which month got the highest sales and orders?
     3. Who purchased more - men or women in 2022?
     4. What are different order status in 2022?
     5. List of top 10 states contributing to the sales.
     6. Relation between age and gender based on number of sales.
     7. Which channel is contributing to maximum sales?
     8. Highest selling category.




Sample Insights :


     1. Women are more likely to buy compared to men (~65%).

     2. Maharashtra, Karnataka, Uttar Pradesh are the top 3 states(~35%).

     3. Age Group(30-49 yrs) is max contributing(~50%).

     4. Amazon, Flipkart and Myntra channels are max contributing(~80%).



Final conclusion to improve Vindra Store Sales :  Target Women customers of age group(30-49 yrs) living in Maharashtra, Karnataka and Uttar Pradesh by showing ads/offers/coupons available on Amazon, Flipkart and Myntra.
